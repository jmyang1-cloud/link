# User workflow requirements

For every new code task in this project:

1. Before editing, fetch the latest code from https://github.com/jmyang1-cloud/link and synchronize the checkout with the relevant remote branch. Inspect local changes first and preserve them; do not overwrite uncommitted work.
2. Make the requested changes and perform appropriate validation.
3. Once the work is complete, immediately commit and push the task's changes to GitHub. The user has authorized this routine commit/push workflow; do not ask again. Include only changes belonging to the task. If authentication, conflicts, or branch protection block pushing, report the concrete blocker and retain the changes.

Use https://pick.airecipe.co.kr as the primary public URL for this site's deployments and user-facing links.

Always leave a handoff note in HANDOFF.md at the repository root when completing work. Record the date (Asia/Seoul), request, changes, validation, commit/push status, deployment status and URL, and any remaining work or blockers. Keep useful prior entries and never include credentials. Commit and push the note with the task; if deployment happens afterward, update the note with the verified outcome and commit/push it as well.
